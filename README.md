# B8A1 – Problem Solving with TypeScript & OOP

This repository contains my solutions and blog posts for the B8A1 assignment. Through this assignment, I practiced different TypeScript concepts and learned more about Object-Oriented Programming (OOP).

## Files Included

- `solutions.ts` – Contains my solutions to all 8 problem-solving tasks.
- `type-vs-interface.md` – Explains the differences between type aliases and interfaces in TypeScript.
- `type-narrowing.md` – Explains type narrowing with simple examples using `typeof`, `instanceof`, and the `in` operator.

## Topics I Practiced

While completing this assignment, I worked with:

- Basic types and optional parameters
- Union types and type narrowing
- Readonly tuples
- Interfaces and generics
- `keyof` and rest parameters
- Classes and inheritance
- Access modifiers (`private` and `protected`)
- Promises and asynchronous functions
